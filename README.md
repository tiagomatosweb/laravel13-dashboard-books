# Laravel na Prática — Dashboard de Livros

Repositório da série **"Laravel na Prática — Dashboard de Livros"** no YouTube. Neste projeto o foco é um **dashboard de livros**: o usuário gerencia livros com operações **CRUD** (criar, listar, visualizar, editar e excluir) usando **Laravel 13**.

🔗 [Playlist no YouTube](https://www.youtube.com/playlist?list=PLcoYAcR89n-pe2M3ng7goeHTMwQNiUxXG)

## Objetivo do Projeto

Aprenda **Laravel** construindo um projeto desde o início, com conceitos explicados no momento em que fazem sentido. Foco total em **rotas, controllers, views, models, migrations, relacionamentos, validação e muito mais**.

Ideal para quem quer aprender Laravel do zero ou está migrando de outro framework e quer entender a forma moderna de desenvolver aplicações web com PHP.

## O que estamos construindo

Um **painel (dashboard) de livros** com CRUD completo: cadastro, listagem, detalhes, edição e remoção de registros, com interface coerente e dados persistidos em banco.

## Tecnologias

- **Laravel 13**
- **PHP 8.2+**
- **SQLite** (banco de dados)
- **Blade** (templates)
- **Eloquent ORM**

## Como acompanhar

Cada branch representa uma aula da playlist no YouTube.

- **`main`**: Contém a documentação do projeto (README)
- **`template-html`**: Contém o layout HTML de referência (apenas HTML + Bootstrap, sem Javascript e sem Vue)
- **`aula-01`**, **`aula-02`**, **`aula-03`**, etc.: Cada branch contém o código completo do projeto ao final daquela aula

**Conceitos abordados:** Rotas, Controllers, Views, Models, Migrations, Eloquent ORM, Validação, Upload de arquivos, Relacionamentos (1:N), Paginação, Flash messages, Blade templates, Artisan commands e muito mais.
